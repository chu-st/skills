# Помочь проекту / Contributing

Полезнее всего конкретные примеры: где второй взгляд изменил решение, где дал
ложную тревогу, где обе модели пропустили одну ошибку. Подойдут исследования,
аналитика, планы, документы и код.

В issue укажите вопрос, версии агентов и запрошенные модели, способ вызова,
ожидаемое и наблюдаемое поведение. Добавляйте только материал, который можно
публиковать. Перед приложением квитанции удалите локальные пути и личные данные.
Обращения можно писать на русском или английском.

Для изменения протокола объясните конкретный отказ, который оно исправляет.
Для нового CLI-адаптера проверьте непустой ответ, ошибки, таймаут, выбранную модель
и отсутствие shell-интерпретации пользовательских данных. Расходы на реальные
вызовы не входят в обычные тесты.

```text
python -m unittest discover -s tests -v
```

Reports and pull requests in English are welcome. Prefer reproducible findings
and small changes. Please distinguish successful execution from a verified claim
about answer quality. No model output or user data is published automatically.
