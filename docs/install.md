# Установка и обновление

Самый простой запуск — [промпт без установки](../prompts/start-ru.md).
Для постоянного использования скопируйте папку `skills/dual-model-review` в каталог
скиллов своего агента. В папке должны остаться `SKILL.md`, `references/` и `scripts/`.

## Claude Code и Codex

Скачайте [репозиторий](https://github.com/chu-st/skills) или клонируйте его:

```text
git clone https://github.com/chu-st/skills.git chust-skills
cd chust-skills
```

Из его корня:

```text
python scripts/install.py --agent both
```

Установщик использует `~/.claude/skills/dual-model-review` для Claude Code и
`~/.agents/skills/dual-model-review` для Codex. Если ваш агент использует другой
каталог, задайте `--target <полный-путь-к-папке-скилла>`.

Проверка обновлений после получения новой версии репозитория:

```text
python scripts/install.py --agent both --check
```

При отличающейся установленной копии сначала посмотрите изменения. Для замены с
сохранением старой версии в `.install-backups/`:

```text
python scripts/install.py --agent both --replace
```

Закройте и откройте новую сессию, если скилл ещё не появился. В Claude Code можно
вызвать `/dual-model-review`, в Codex — `$dual-model-review`, либо назвать метод
обычным текстом. Наличие скилла не добавляет учётную запись второй модели.

## Постоянная связь с локальным Git-репозиторием

Для разработчика удобна символическая ссылка, а на Windows — junction, из папки
установки на папку скилла в клоне. Тогда смена проверенной версии клона сразу
меняет скилл. Существующую копию сначала сохраните в резервную папку и проверьте
её отличия. Установщик умеет проверять ссылку, уже ведущую на правильный источник,
но не заменяет чужие ссылки автоматически.

Закрепляйте проверенный тег или commit, если вам важна неизменность поведения.
Не правьте установленную копию отдельно от источника. Внутренние проектные правила
добавляйте через инструкции своего проекта, не публикуя их в общий пакет.

## Автоматический вызов второй модели

Установите и авторизуйте нужные CLI через их официальные инструкции:
[Claude Code](https://code.claude.com/docs/en/overview),
[Codex](https://learn.chatgpt.com/docs/codex-cli).
Python 3.10+ нужен только для помощника запуска.

На Windows помощнику нужен родной исполняемый файл, а не `.cmd`-обёртка.
Посмотрите `Get-Command claude -All` или `Get-Command codex -All`. Если команда
указывает только на обёртку, найдите родной файл по официальной инструкции
установки провайдера и передайте полный путь через `--executable`.

Вторая модель выбирается в промпте или параметром `--model`; её имя не зашито в метод.
Команды и способы подключения других моделей — в [описании транспорта](../skills/dual-model-review/references/transports.md).
