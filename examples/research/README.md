# Пример: действительно ли ИИ ускорил поддержку

Это **учебный синтетический пример** для проверки метода. Он не описывает клиента
chu.st и не является измерением эффекта двух моделей.

Передайте [brief.md](brief.md) двум моделям независимо. Не показывайте им контрольные
расчёты до того, как оба первоначальных ответа будут сохранены.

В Claude попросите проверить вопрос второй моделью Codex. Затем попробуйте обратное
направление из Codex с Claude. Если CLI недоступен, используйте два отдельных чата.
Для автоматического транспорта задайте явную модель и новый каталог результатов:

```text
python skills/dual-model-review/scripts/peer.py --provider claude --model opus --prompt examples/research/brief.md --output .runs/research-claude
python skills/dual-model-review/scripts/peer.py --provider codex --model YOUR_CODEX_MODEL --prompt examples/research/brief.md --output .runs/research-codex
```

Модели должны сами определить, какие выводы следуют из данных. Проверьте затем
материальные расхождения с помощью [контрольного разбора](expected.md).

Приёмка примера: итог различает арифметическую верность общего среднего и
необоснованный причинный вывод, учитывает состав заявок и неполноту опроса,
предлагает собрать недостающие данные. Простого согласия моделей недостаточно.
